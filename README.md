# Raylib Projects

To run demos 

Windows: 
- install zig 
- run build.bat in each folder

Linux

- Debian / Ubuntu: ```sudo apt install libraylib-dev```
- Arch Linux: ```sudo pacman -S raylib```
- Fedora: ```sudo dnf install raylib-devel```

run ```gcc main.c -o main -lraylib -lGL -lm -lpthread -ldl -lrt -lX11``` in each folder
